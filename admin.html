Token yalnızca bu tarayıcıda saklanır; repoya yazılmaz, GitHub dışında hiçbir sunucuya gönderilmez.
Token nasıl alınır?
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Generate new token
  3. Repository access: Only select repositories → sadece bu repoyu seç
  4. Permissions → Repository permissions → Contents: Read and write (başka hiçbir izin verme)
  5. Bir son kullanma tarihi seç, oluştur ve token'ı buraya yapıştır

Ortak kullanılan bir bilgisayardaysan işin bitince sağ üstteki Çıkış ile token'ı sil.
